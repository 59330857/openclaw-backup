## 21:23 — HALEI 提的需求：停 cron 通知 + 飞书任务同步

**HALEI 原话**：
> 你不要发cron job的通知给我了。是不是可以把这个任务同步也加入到飞书的任务中，执行一个勾选一个，我也可以通过任务来查看，让所有的agent 每天执行的cron job这些任务都能和飞书的任务同步是否可以好？

### 我的理解
1. **停 cron 完成通知**（除非异常/failed）
2. **所有 agent 的每日 cron job 同步到飞书任务清单**：
   - 结构化、可勾选、可查看历史
   - 执行完自动勾选
   - 失败保持 open 人工追

### 待 HALEI 确认的 4 个问题
1. **飞书任务承接载体**：
   - A. 每个 agent 一个清单（推荐）
   - B. 一个总清单
   - C. 按业务域分
2. **同步机制**：
   - A. cron 末尾直接调飞书 API（改 cron 提示词）
   - B. main 每天汇总一次批量写（有延迟）
3. **范围**：只同步当前在跑的（推荐）/ 历史全部追溯
4. **勾选节奏**：实时勾 / 每日一次

### 初步方案
- 每 agent 一个清单：「[agent名] 每日任务」
- 每个 cron job → 该 agent 清单下的 recurring 任务
- cron 跑完 → 飞书 API 勾选 + 记录完成时间
- 失败 → 不勾选，人工介入
- 通知 → 仅 failed 时推送

### 落地方向
- 等 HALEI 拍板 4 个问题
- 由 agent-orchestrator 出执行清单
- main 不直接动 agent 配置（边界）
